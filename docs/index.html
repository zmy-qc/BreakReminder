v1.1.0 · macOS 13+ / Windows 10+ · Apple Silicon / Intel 通用 · 纯本地运行，无遥测

它做什么

⏱ 连续工作计时按键鼠活动累计；离开超过 5 分钟视为已休息，回来重新计时
🔔 一小时提醒居中弹窗大数字倒数 5 秒（可调），一键进入休息或本次跳过
🌊 屏保休息五分钟播放系统自带屏保动画，底部半透明浮层显示剩余时间；触碰键鼠立即结束
☕ 菜单栏/托盘常驻随时看进度、立即休息、暂停监控、调整参数、开关开机自启

安装 — macOS（3 步）

  1. 下载 BreakReminder-macOS.zip 并解压，得到 BreakReminder.app；
  2. 拖入「应用程序」文件夹，右键 → 打开 → 打开（自用软件无开发者签名，首次绕过一次即可）；
  3. 菜单栏出现 ☕ 图标即完成，已自动设置开机自启。

若 macOS 提示「已损坏，无法打开」（新系统对未签名下载软件的限制），在终端执行后再打开：

xattr -cr /Applications/BreakReminder.app

安装 — Windows（1 步）

  1. 下载 BreakReminder-Windows.zip 并解压，双击 BreakReminder.exe， 托盘（右下角）出现 ☕ 图标即运行。单文件约 20 KB，无需安装任何运行时 （Win10/11 自带 .NET Framework）。首次运行若被 SmartScreen 拦截： 「更多信息 → 仍要运行」。右键托盘图标可开启开机自启。

休息的规则

触发时居中弹出深色卡片，大数字倒数 5 秒（可调）后自动进入屏保，也可点「进入休息」或「本次跳过」。休息期间屏幕底部显示半透明倒计时浮层（点击完全穿透，不遮挡屏保画面）；期间触碰键鼠，休息立即结束、恢复工作（开始 3 秒为防误触宽限）；一直离开则满 5 分钟结束——Windows 版到点自动关闭屏保恢复桌面，macOS 版回来一碰键鼠即恢复。软件完全离线运行，不联网、不收集任何数据。
